Skill Wizard

Build a model-portable SKILL.md: plain Markdown, no platform hooks, readable by any LLM. Model assist runs on whichever engine you pick.

Engine: Claude (in-app)

Identify the skill

Name it short and specific. The name becomes the folder and the frontmatter name: field.

→ folder: your-skill/SKILL.md

Wire the triggers

Phrases and situations that should activate this skill. They land in the description and in the Trigger Scenarios section.

Write the execution steps

One step per line, imperative voice ("Extract the dates"). Numbering is added for you. Rigid process: spell out each step. Creative task: state goals instead.

Set the guardrails

Checks and failure modes. One per line, e.g. required fields to validate, things to avoid, output limits.

Assemble and check portability

Heuristic checks against the portable-skill rules. Fix warnings by hand or let the model rewrite the whole skill.

    → your-skill/SKILL.md
    Name the skill in step 1 to start assembling.
    Model buttons call the engine chosen above and send your skill text to it. The key stays in this page's memory only. Nothing is stored; refreshing clears the form. Naming, triggers, linting and export work fully offline.
